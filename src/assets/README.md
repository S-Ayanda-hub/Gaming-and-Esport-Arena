# Images

All images used by the app live here. Replace any file with your own artwork
using the same filename and nothing else needs to change:

- logo.png - brand mark (header dot, web favicon)
- hero.png - Home screen hero banner background
- avatar-viper.png / avatar-glitch.png / avatar-zero.png - leadership avatars on About
- offerings/*.png - card image for each of the seven offerings

Files are referenced from src/data/offerings.ts and src/data/team.ts via
require(), so keep filenames identical when swapping artwork.
